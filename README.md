# Ultron: my Claude Code mods

A plugin marketplace (`my-mods`) with one mod, **cc-combo**: savvy-progress, filetree, cache-tax and blast-radius in one plugin with one shared look. See [cc-combo/README.md](cc-combo/README.md).

## Install

Needs Claude Code 2.1.287 or later (`claude update`). In Claude Code:

```
/plugin marketplace add dominpin/Ultron
/plugin install cc-combo@my-mods
```

Choose the **user** scope so it loads in every session.
